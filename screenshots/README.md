# Screenshots Directory

This directory contains screenshots for the DevLauncher project documentation.

## Required Screenshots

Please add the following screenshots (PNG format recommended):

### Main Interface
- `main-dark.png` - Main interface in dark theme
- `main-light.png` - Main interface in light theme

### Key Features
- `add-project.png` - Add project dialog showing project detection
- `batch-import.png` - Batch import dialog with directory scanning
- `startup-profiles.png` - Startup profiles configuration
- `group-management.png` - Group management dialog
- `batch-actions.png` - Batch operations mode
- `log-viewer.png` - Log viewer with real-time output

### Additional (Optional)
- `settings.png` - Settings/preferences dialog
- `language-switcher.png` - Language switcher in action
- `grid-view.png` - Grid view layout
- `list-view.png` - List view layout

## Screenshot Guidelines

1. **Resolution**: Recommended 1920x1080 or similar 16:9 ratio
2. **Format**: PNG (for quality) or WebP (for size)
3. **Content**: Show realistic data, not empty states
4. **Theme**: Include both dark and light variants for main interface
5. **Language**: English is preferred for broader audience
